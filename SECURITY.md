# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues.

Email privacy@orkes.io with:

- a description of the problem and its impact,
- the affected version,
- steps to reproduce, or a proof of concept.

We will acknowledge your report, keep you informed while we work on a fix,
and credit you in the release notes if you wish.

## Supported versions

Security fixes are made for the latest released version.
